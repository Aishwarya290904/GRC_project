# BrightPay Risk Assessment
A simulated information security risk assessment for a fictional fintech company.

## What's inside
- Risk Register (Excel): 7 risks scored with Likelihood x Impact
- Heat Map (PNG)
- Report (PDF): summary, findings, and action plan

## Method
1. Define scope 2. Identify assets 3. Identify threats and vulnerabilities
4. Score risks (1-3 x 1-3) 5. Choose treatment: Mitigate, Transfer, Avoid or Accept

Note: BrightPay is fictional. This is a learning project.
